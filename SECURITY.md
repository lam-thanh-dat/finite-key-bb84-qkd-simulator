# Security Notice

This repository is an educational Monte Carlo model. It is not a production
cryptographic implementation and must not be used to generate, distribute, or
validate keys for real security systems.

The program estimates information-theoretic key lengths. It does not implement
authenticated classical communication, a production error-correction code,
universal-hash privacy amplification, decoy-state parameter estimation, or a
composable finite-key security proof.

Please report implementation defects through a GitHub issue. Do not submit real
keys, credentials, personal data, or confidential experimental data.
