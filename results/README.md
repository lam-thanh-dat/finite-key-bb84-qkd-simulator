# Reproduced Results

These files are generated by:

```bash
python scripts/reproduce_bb84_results.py \
  --publication --sync-paper-figures
```

- `bb84_reference_scenarios.json` contains deterministic single-run checkpoints for
  the baseline, intercept-resend, intrinsic-error, high-loss, and weak-source
  cases.
- `bb84_intercept_resend_sweep.csv`,
  `bb84_intercept_resend_sweep.png`, and
  `bb84_intercept_resend_sweep.pdf` show the relation between intercept-resend
  probability, QBER, and the asymptotic secret fraction.
- `bb84_finite_key_scaling.csv`, `bb84_finite_key_scaling.png`, and
  `bb84_finite_key_scaling.pdf` compare the illustrative finite-size estimate with
  the corresponding asymptotic estimate. The PDF figures are vector graphics
  intended for publication; the PNG files are high-resolution previews.

The shaded intervals are 95% normal confidence intervals for the Monte Carlo
mean across deterministic independent seeds. They describe simulation
variability, not experimental uncertainty and not a cryptographic security
guarantee.

The synchronization option copies the two generated vector PDFs into
`paper/figures/`, preventing the paper from retaining stale plots. To verify
that the tracked numerical files are current without overwriting them, run:

```bash
python scripts/reproduce_bb84_results.py --check
```

PDF export embeds creation and modification timestamps, so vector-PDF byte
hashes can change between runs even when the rendered figures are identical.
The hashed environment lock fixes the Python dependency graph; numerical files
and PNG previews remain suitable for exact drift checks.
